# Core Content

core_features:
  - Blink rendering engine (forked from WebKit in 2013)
  - V8 JavaScript engine with WebAssembly + WebGPU
  - Multi-process Chromium with per-origin site isolation since 2018
  - Chrome Sync across desktop + Android (best in class)
  - Chrome Web Store — largest extension ecosystem
  - DevTools — industry-leading web developer tools
  - Gemini Nano on-device LLM for Pro subscribers (since 138)

# Key Information

highlights:
  - De facto standard for web compatibility
  - ~76% desktop share (StatCounter Q2 2026)
  - On iOS, Chrome uses WebKit due to Apple policy
  - Privacy Sandbox replaces third-party cookies (Topics / FLEDGE / Attribution) — phased 2024-2026
  - Manifest V3 stable since Chrome 100; V2 deprecated in 2024
  - Engine = Blink (shared with Edge, Brave, Arc, Vivaldi, Opera)

# Summary

Chrome is the canonical "compatibility + ecosystem" browser — Google-built, Blink engine, ~76% desktop share. It's the open-source Chromium's flagship distribution; most "Chromium-based browsers" share the same Blink + V8 engine under different UI shells. Chrome ships the best-in-class sync (Google account), industry-leading DevTools, the largest extension ecosystem (Chrome Web Store), and Gemini Nano on-device LLM for Pro subscribers since 138. Privacy Sandbox replaces third-party cookies via Topics / FLEDGE / Attribution APIs (phased 2024-2026). On iOS, Chrome uses WebKit due to Apple policy. Verdict: recommended if you're in the Google ecosystem or want maximum compatibility; skip if engine independence or strong privacy defaults are top priority.
