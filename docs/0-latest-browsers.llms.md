# Key Information

highlights:
  - Local / on-device AI models are the 2026 trend (Brave Leo local, Chrome Gemini Nano on-device for Pro)
  - Firefox's decline has flattened since 2024 on Manifest V3 + privacy focus
  - Privacy Sandbox's Topics API continues incremental rollout in Chrome 140+
  - Safari 19 dropped macOS 12 Monterey; minimum is macOS 13 Ventura
  - Servo (Rust-based engine) is funded by Linux Foundation Europe; not consumer-ready
