# Summary

Browser AI in 2026 is table stakes. Two inference models: cloud (Copilot, Gemini Pro, Apple Intelligence cloud) sees your inputs and runs frontier models with full capability; local (Gemini Nano, Brave Leo local, Apple Intelligence on-device) keeps data on-device but limited to smaller models. Per-browser: Chrome (Gemini Nano for Pro + Gemini Pro cloud + AI Overview), Edge (Microsoft Copilot cloud), Safari (Apple Intelligence on-device by default, cloud optional), Brave (Leo with local default + cloud paid tier), DuckDuckGo (DuckAssist + AI Chat cloud, proxied for privacy), Arc (Boosts + Easels + AI Search cloud), Vivaldi (no AI default — user opt-in). Local inference hardware: Apple silicon M1+ (unified memory, efficient), Snapdragon X / Intel Core Ultra / AMD Ryzen AI (NPUs), older hardware (cloud only). AI Overview citation strategies: long-form first-hand content, original data, expertise signals, structured data — NOT SEO fluff. Threat-model-based selection: Apple Intelligence or Brave Leo local for max privacy; DuckDuckGo or Brave Leo cloud for balance; Chrome Pro or Edge Copilot for max capability; Vivaldi for no AI.
